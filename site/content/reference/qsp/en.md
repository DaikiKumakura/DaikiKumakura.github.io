QSP models connect drug action to interacting biological processes and their dynamics ([Braakman et al. Evaluation framework for systems models. CPT Pharmacometrics Syst Pharmacol. 2022.](https://doi.org/10.1002/psp4.12755)).

A T-cell engager model might link drug exposure and target binding to T-cell activation and tumor-cell killing. Cell assays can constrain killing rates, while clinical data can test predictions in humans. If several parameter sets fit the calibration data equally well, compare their predictions before using the model to rank regimens.
