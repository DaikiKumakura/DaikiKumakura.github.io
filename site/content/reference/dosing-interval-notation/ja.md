## 意味

投与方式の**Q**は、ラテン語のquaque（毎）に由来する。その後に、数字と時間の単位が続く。

| 表記 | 意味 |
| --- | --- |
| QD | 1日1回 |
| BID | 1日2回 |
| Q8H | 8時間ごと |
| Q1W（QW） | 毎週 |
| Q2W | 2週ごと |
| Q3W | 3週ごと |
| Q4W | 4週ごと |
| Q6W | 6週ごと |

## 抗体医薬の例

- pembrolizumab：200 mg Q3W、または400 mg Q6W。
- nivolumab：240 mg Q2W、または480 mg Q4W。
- 体重換算の形：2 mg/kg Q3W、3 mg/kg Q2W。用量が体重に比例する。

投与間隔と用量を同時に2倍にすると、平均曝露は同じで、トラフは下がり、ピークは上がる。[Ctrough](ctrough-trough-concentration-ja.html)と[抗PD-1抗体の曝露エクスプローラー](../tools/anti-pd1-exposure-ja.html)を参照。
