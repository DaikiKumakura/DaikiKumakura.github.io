Models from the literature that the analyses on this site reimplemented, fitted to public data or reused with published estimates. All analyses use public information or simulation only and are research and learning analyses, not dosing proposals. Whether a model was *reimplemented from a paper* or *estimated from public data* is stated for each row, because the two support different claims (see [reimplementing a published population PK model](../glossary/poppk-reimplementation.html)).

## Notes

- Agreement with published values shows that a model was rebuilt correctly. It does not validate the model for predicting another population or regimen.
- Where a source contained an inconsistency (for example a table value that differs from its footnote), the articles report it and test both versions.
- The [distribution file of the anti-PD-1 analysis](../writing/shared/fixed-vs-weight-dosing/fixed-vs-weight-dosing-companion.zip) contains the code, results and an independent recalculation.
