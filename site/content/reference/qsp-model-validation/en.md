## Definition

Verification checks that a model is implemented correctly: equations, units and code produce the intended results. Validation assesses whether its predictions reproduce relevant observations for the intended use. Calibration, fitting parameters to data, is a separate step.

## How it is used

The level of evidence is scaled to the model's role. A risk-informed credibility framework such as ASME V&V 40 relates required evidence to the influence of the model on the decision and the consequence of a wrong decision. Verification includes unit tests and replicate implementations; validation uses datasets or conditions not used for calibration.

## Common pitfalls

- Reporting agreement with calibration data as validation.
- Reporting a single best-fit parameter set without the uncertainty of the predictions, or testing only on conditions close to the fitted ones.
