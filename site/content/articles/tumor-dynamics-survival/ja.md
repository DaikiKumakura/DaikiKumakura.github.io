## 要旨 {#revision-section-1}

大腸がん試験の公開部分集団で、早期の腫瘍変化が、その後の生存予測に追加情報を与えるかを調べた。未使用患者での識別能はわずかに改善したが、改善幅の区間は改善なしを含み、較正にも弱さが残った。この結果は追加の予測研究を検討する根拠にはなるが、生存の代替指標や治療判断の規則を支持するものではない。

## 背景と目的 {#revision-section-2}

問いは、早期腫瘍計測が、ベースラインの臨床因子と腫瘍量だけを使う場合に比べ、その後の全生存期間について未使用患者での予測情報を加えるかである。用途は、早期モニタリングを予測研究の対象として検討するための評価であり、治療切替、用量変更、因果的媒介、生存の代替指標としての適格性は扱わない。

各患者で最も小さくなった腫瘍値を、いつ測られたかを問わず治療開始時からの生存予測に使うと、予測時点では得られなかった情報を利用してしまう。長く生存した患者ほど反応を記録する機会も増える。本解析では予測時点を16週に固定し、それ以前の計測だけを予測因子に用いた。

## 方法 {#revision-section-3}

### データと整合性の確認 {#revision-section-4}

frailtypack 3.8.1に収録された `colorectal` と `colorectalLongi` は、転移性大腸がんで逐次化学療法と併用化学療法を比較したFFCD 2000–05試験から無作為に抽出された150人の部分集団である。Chiouらの資料では、当該データの時間単位が年であることと、保存された年齢区分を確認できる。今回は配布された部分集団の二次解析であり、無作為化試験全体の再解析ではない ([1](#ref-1), [2](#ref-2))。

整合性の確認結果を表1に示す。

<span id="table-1"></span>表1．データの整合性と解析上の扱い

| 確認項目 | 確認結果と解析上の扱い |
| --- | --- |
| 参加者 | 150人。縦断計測906件、生存・反復イベント区間289件 |
| 終末イベント | 除外前に死亡121人、右打切り29人 |
| 記録の対応 | ファイル間で参加者IDと保存された臨床区分が一致 |
| 時間の不整合 | 死亡記録より後の計測が1件あり、主解析では当該参加者を除外 |
| 腫瘍値の尺度 | Box–Cox変換済み。lambdaは0.3、下限で打ち切られた計測が34件 |
| 評価項目 | 全生存期間。新病変の記録を、定義が確認された無増悪生存期間として扱わない |
| 年齢区分 | 保存された60歳未満、60–69歳、69歳超を使用。パッケージ説明との不一致は残す |

時間の不整合も年齢区分も、黙って修正しなかった。感度分析では、時間が不整合な計測だけを除き、当該参加者は残した。配布する付属資料に患者単位の記録は含めず、取得・書出しスクリプトで公式配布元から取得する。ソフトウェアのライセンスだけで、元の臨床データの利用権すべてが確認できるわけではない。

### ランドマークの定義と予測因子 {#revision-section-5}

主解析のランドマークは16週とし、1年を52.1775週として換算した。対象は、ランドマークより後まで生存・観察され、ベースライン腫瘍計測と、時刻0より後かつ16週以前の計測が少なくとも1件ある参加者である。整合性による除外後、主解析には128人が入り、その後の死亡は101人だった。したがって対象集団は、無作為化された全参加者ではなく、この観察条件を満たす部分集団である。

同じ参加者を用いて二つのCoxモデルを比較し、推定にはsurvivalパッケージを使った ([3](#ref-3))。予測因子を表2に示す。

<span id="table-2"></span>表2．ランドマーク時点で利用できる予測因子

| モデル | 予測因子 |
| --- | --- |
| 臨床因子モデル | 治療群、年齢区分の二つの指示変数、WHO status ≥1、切除歴、変換後のベースライン腫瘍量 |
| 臨床因子＋早期変化モデル | 臨床因子に加え、最後の早期腫瘍値からベースライン値を引いた差と、その計測時点 |

同じ変化量でも、早期の計測と16週に近い計測では観察窓が異なるため、計測時点も予測因子にした。拡張モデルは観測された特徴量を使うモデルであり、機序的な腫瘍増殖抑制モデルではない。少数の早期計測だけでは、個人ごとの増殖率と殺細胞率の推定は正当化できない。

主解析の1人では、最後の計測が下限で打ち切られていた。変換前の非負の腫瘍値に対応する下限−1/0.3と、記録された丸め後の下限−3.33を用いて、範囲を限定した感度分析を行った。これは近似的な感度分析であり、打切りを扱う縦断尤度ではない。すべてのベースライン・追跡計測の下限打切りを処理するものでもない。腫瘍値をmmやRECISTの変化率として解釈しない。

### 検証と不確実性 {#revision-section-6}

患者を分離した5分割を、固定した乱数シードで10回繰り返した。各Coxモデルとベースラインハザードは学習側で推定し、評価患者の将来の計測を予測因子に使わなかった。未使用患者での反復予測を患者ごとに平均したため、評価対象は交差検証によるアンサンブルであり、最終的に一度だけ推定したモデルの性能ではない。

評価指標はconcordance、1年時点の打切り逆確率重み付け（inverse probability of censoring weighting、IPCW）Brier score、較正とした。学習分割で推定した1年時点の打切り生存確率は最低0.963で、事前設定した下限0.20を上回った。平均予測の評価では、打切り分布の推定値も反復間で平均した。これは反復cross-fittingによるIPCW評価の近似である。

平均した予測値を固定し、患者単位の対応付きブートストラップを1,000回行って区間を求めた。この区間は再推定に伴う不確実性を含まず、前向きの外部検証で得られる区間でもない。

![ランドマーク適格集団における未使用患者の生存確率の較正。](shared/tumor-dynamics-survival/figures/heldout-calibration.png)

*図3．ランドマーク適格集団での、その後の生存予測の較正。患者を分離した反復分割の予測を平均した。本記事の解析。*

全データで推定した拡張モデルでは、変換後の腫瘍量の増加が生存の悪化と関連した。しかし、その関連だけで有用な予測が得られたとは言えない。Schoenfeld残差による検定では、モデル全体の比例ハザード性からの逸脱は検出されなかった（臨床因子モデルのp = 0.58、拡張モデルのp = 0.76）。検定力には限界があり、この結果でモデルの妥当性が保証されるわけではない。

ランドマークと整合性の扱いを変えた結果を表4に示す。

<span id="table-4"></span>表4．ランドマークと整合性の感度分析

| 条件 | 人数／死亡数 | 臨床因子C | 拡張C | 臨床因子Brier | 拡張Brier |
| --- | ---: | ---: | ---: | ---: | ---: |
| 12週 | 116 / 91 | 0.551 | 0.588 | 0.2531 | 0.2469 |
| 16週の主解析 | 128 / 101 | 0.532 | 0.581 | 0.2543 | 0.2492 |

ランドマークを変えると、適格性と利用可能な情報が変わる。24週の結果は、計測を遅くまで待つ方が臨床方針として優れる証拠ではない。下限値の感度分析では、主解析と同じ分割を使い、拡張モデルのBrier scoreの変化は0.000001未満だった。この小ささは今回の限定した数値上の仮定に対する結果であり、選択バイアスを除いたり、腫瘍尺度を検証したりするものではない。

## 考察 {#revision-section-10}

早期腫瘍変化には、その後の生存との関連が残り、未使用患者でのスコアはわずかに改善した。ただし、不確実性と較正の弱さにより、それ以上の予測上の主張は支持できない。少数の縦断計測と、計測が行われる過程そのものも、推定した軌道の解釈を制約する。

## 結論 {#revision-section-11}

早期腫瘍変化が臨床因子モデルに加えた未使用患者での情報は小さく、改善なしを含む区間と較正の弱さが残った。生存の代替指標や治療判断の規則を支持する結果ではない。

元の試験が無作為化されていても、ランドマークで選択された部分集団の二次解析が、治療方針の因果比較になるわけではない。腫瘍変化と生存に対する治療効果だけでは代替指標としての適格性は示せず、このデータには用量・曝露・腫瘍・生存をつなぐためのPKと投与履歴もない。
