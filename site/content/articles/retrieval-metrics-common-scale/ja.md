## 背景と目的

Perturb-seq の評価では、細胞の状態から「どの摂動がかかったか」を候補の中から当てる課題（retrieval）が増えている。報告される数字は論文ごと・競技ごとに違う。ExPert は top-10 recall と「偶然の何倍か」で報告し ([1](#ref-1))、Arc Institute の Virtual Cell Challenge の解説は摂動識別スコア（PDisc とその正規化）を示し ([2](#ref-2))、PerturBench は 0 を完全、0.5 をランダムとする順位指標を使う ([3](#ref-3))。RNA fingerprinting は、答えを出さない（棄権する）選択肢を持つ ([4](#ref-4))。

これらは互いに換算できるのか。換算できるなら、何が比べられて、何が比べられないのか。本稿は、真の候補が他の候補よりどれだけ高い得点を取るかという一つの識別力のものさしを置き、ExPert が公開した図のソースデータ ([5](#ref-5)) に当てはめて確かめる。モデルは単純な仮定に基づく見方であり、各手法の仕組みを主張するものではない。解析計画は計算の前に固定しておらず、当てはめたパラメータの信頼区間は計算していない。混合モデルの当てはめ、保留した k での内挿の確認、画面（スクリーン）ごとの有効な識別力は、結果を見ながら加えた探索的な解析である。

## 要旨

候補が N 個ある当てもの課題に、M 択強制選択の信号検出モデル（真の候補の得点は平均 d′ の正規分布、他の候補は平均 0 の正規分布、分散はいずれも 1）を置くと、top-k recall、平均逆順位（MRR）、順位の割合に基づく識別スコアは、d′ と N から計算できる。N = 1,157 では、d′ = 2 のとき正規化した識別スコア（1 − 2·PDisc）が 0.84、top-10 recall が 0.35、偶然に対する倍率が 40 倍である。ExPert の公開された recall@k（k = 1, 5, 10, 20, 50, 100）に当てはめると、すべての問い合わせに同じ d′ を置くモデルは合わない（k = 1, 10, 100 で当てはめ、保留した k = 5, 20, 50 の二乗平均平方根誤差 RMSE は、学習に使った文脈（ID）で 0.082、学習から除いた文脈（OOD）で 0.084）。問い合わせごとに d′ が異なるとすると、2 パラメータの連続分布でも 3 パラメータの 2 成分混合でも保留した k を 0.01 未満の誤差で内挿し（3 点に滑らかな曲線を当てるため弱い検証である）、ExPert では当てはめに使っていない MRR も 0.01 以内で再現した（OOD の観測 0.376、混合の予測 0.376）。問い合わせごとの違いは、単一 d′ が合わない理由として考えられる説明の一つである。top-10 recall 50% に必要な d′ は、候補 200 個で 1.66、19,895 個で 3.30 で、候補を約 100 倍にしても d′ の増分は 1.64 である。倍率は N に強く依存するため、N が異なる値は N を併記しないと比べられない。報告値を読む際には、倍率の重み付け、問い合わせの構成、棄権の扱いを確認する必要がある。

## 方法

### 識別力のモデル

候補が $N$ 個あり、そのうち 1 個が真の摂動である。真の候補の得点を $S \sim \mathcal{N}(d', 1)$、他の $N-1$ 個の得点を独立に $\mathcal{N}(0,1)$ とする。真の候補の順位は、$S$ を超える他の候補の数に 1 を足したものである（同点は考えない）。$S = s$ のとき、他の候補が $s$ を超える確率を $q(s) = 1 - \Phi(s)$ とすると、次が成り立つ。

$$
\mathrm{top}\text{-}k = \mathbb{E}_S\!\left[\Pr\big(\mathrm{Bin}(N-1,\,q(S)) \le k-1\big)\right],\quad
\mathrm{MRR} = \mathbb{E}_S\!\left[\frac{1-(1-q(S))^{N}}{N\,q(S)}\right],\quad
\mathrm{AUROC} = \Phi\!\left(d'/\sqrt{2}\right)
$$

ここで $\Phi$ は標準正規分布の累積分布関数、$\mathrm{Bin}$ は二項分布、AUROC は真の候補と 1 個の他の候補を比べたときに真の候補が高い確率である。順位の割合に基づく識別スコア（PDisc）は、他の候補のうち真の候補より近いものの割合の期待値 $\mathrm{PDisc} = 1 - \Phi(d'/\sqrt{2})$ と置き、正規化した値を $1 - 2\,\mathrm{PDisc}$ とする。Virtual Cell Challenge の解説の定義（マンハッタン距離で並べた順位を総数で割り、2 倍して 1 から引く）と似た形の量である ([2](#ref-2))。ただし仮想的な順位の割合の尺度であり、その採点の換算ではない。実際の採点は距離、候補集合、平均の取り方が異なる。偶然に対する倍率は、top-k を $k/N$ で割った値である（$k$ は数える上位候補の数）。モデルでは同点を考えない。原著は同点を半分として数えており ([1](#ref-1))、得点が粗いと recall と MRR がわずかに高くなりうる。M 択強制選択で d′ を使う枠組みは、心理物理学の古典的な d′ の表（Hacker と Ratcliff）に対応する。この表は正答率、つまり top-1 に関するものである ([6](#ref-6))。top-k と MRR への拡張は本稿で行った。本稿はその表の数値を引用せず、上の式を数値積分（格子 4,001 点）で計算した。

問い合わせごとに d′ が異なる場合は、d′ の分布で上の量を平均する。$\pi$ は強い問い合わせの割合である。次の 3 族を比べた。

- 単一の d′（1 パラメータ）
- d′ が正規分布 $\mathcal{N}(\mu, \tau^2)$ に従う（2 パラメータ。ガウス・エルミート 41 点で積分）
- 強い問い合わせ $d'_1$ と弱い問い合わせ $d'_2$ の 2 成分混合（割合 $\pi$ を含む 3 パラメータ）

### データと当てはめ

入力は、ExPert の図のソースデータ（Zenodo、CC BY 4.0）に含まれる `fig2a_radar_ext.csv` である ([5](#ref-5))。ExPert と基準手法について、学習に使った文脈の保持細胞（ID）と学習から除いた文脈（OOD）の、候補 1,157 個に対する pseudobulk（1 データセットの 1 摂動の全細胞を平均した 1 本のプロファイル）の問い合わせの recall@k（k = 1, 5, 10, 20, 50, 100）、MRR、AUROC が入っている。原著の方法では、指標はデータセットと分割の組ごとに計算し、摂動ごとに 1 票として平均している ([1](#ref-1))。MRR の定義は原著に書かれている ([1](#ref-1))。AUROC の定義は、私が読んだ原著の本文には見当たらなかった。モデルの AUROC は「真の候補と 1 個の他の候補の比較」であり、公開値がこれと同じ定義であるかは確認できていない。AUROC の一致は、定義が同じ場合の整合性の確認にとどまる。

当てはめは、k = 1, 10, 100 の recall の二乗誤差の和を最小化し（Nelder-Mead 法）、保留した k = 5, 20, 50 の recall、MRR、AUROC を予測して公開値と比べた。ExPert の 2 条件に加え、重心照合の基準手法、XGBoost、線形回帰でも同じ手順を実行した（計 8 条件）。当てはめたパラメータと RMSE の信頼区間は計算していない。モデルの数値積分は、乱数（シード 20261107）によるモンテカルロ・シミュレーションと照合した。20,000 問い合わせの recall と MRR は、d′ = 1, 2, 3 で積分値と 0.004 以内で一致した。

### 公開値の再集計

ExPert のゼロショット検索（候補 19,895 遺伝子）の倍率は、原著の図 3 の公開データ（12 個の交差検証の分割、各 1 モデル） ([5](#ref-5)) から、重みなし、効果量による重み付けの 2 通りで再集計した。棄権は、原著の図 S4 の公開された元データを再集計した ([5](#ref-5))。再学習は行っていない。画面ごとの有効な d′ は、画面ごとの重みなし top-10 recall を、N = 19,895 の単一 d′ モデルの値へ逆算したものである。実際の問い合わせ集団は混合なので、これは「同じ top-10 recall を与える単一 d′」という便宜的な値である。

事実として言えるのは次の点である。単一の d′ は、保留した k の recall を 0.08 程度外す。OOD では MRR が 0.271 と観測値 0.376 を大きく下回り、AUROC は 0.948 と観測値 0.845 を上回る。問い合わせごとに d′ が異なるモデルは、保留した k の recall を 0.006 以内で再現したが、3 点に滑らかな曲線を当てた内挿が主であり、どちらの族にとっても弱い根拠である。3 点で一意に決まらない 2 パラメータの当てはめの方が、3 パラメータより重みがある。MRR は連続分布で 0.372、混合で 0.376 と観測値に近い。AUROC は、問い合わせごとに d′ が異なるどちらの族も約 0.025 以内に合わず（OOD で連続分布 0.830、混合 0.867、観測 0.845）、AUROC は両者を区別しない。明確な差は、ID の単一 d′（0.990 対 0.958）だけである。混合の当てはめでは、ID で強い成分 $d'_1$ = 4.07、弱い成分 $d'_2$ = 1.55、強い成分の割合 0.72、OOD で 3.57、0.88、0.51 だった。連続分布の当てはめは、ID で平均 3.65、標準偏差 1.65、OOD で平均 2.27、標準偏差 1.91 である。

8 条件全体では、単一 d′ の保留 k の RMSE は 7 条件で約 0.028 以上、連続分布は最大 0.011、混合は最大約 0.004 だった。例外は XGBoost の OOD で、recall が偶然に近いため 3 族とも 0.003 だった。

解釈としては、公開された曲線が棄却するのは、等分散で候補が独立という、d′ が 1 つのモデルである。問い合わせごとの違いは説明の一つにすぎない。浅い recall 曲線は、相関した候補やハブ的な候補、分散の違い、裾の重い得点や有界な得点、真の候補を取り出せない問い合わせでも生じる。公開値からはこれらを区別できない。分割・データセット・摂動にわたる平均（摂動ごとに 1 票）がそれ自体で混合を作りうる。異質性の直接の根拠は、表 5 のような分割ごと・画面ごとのデータである。連続分布と混合は曲線ではほぼ区別できないので、2 成分という形は支持されない。OOD の正規分布の当てはめは、質量の約 12% が負の d′ にあり、識別力として解釈できない。3 パラメータの混合は 3 つの当てはめ点で一意に決まるので、本当の検証は保留した k、MRR、AUROC であり、最も情報があるのは MRR である。

### 報告値を読む際の確認点

ExPert の公開値で、同じ「偶然に対する倍率」が定義によってどう動くかを調べた（`analysis/01_zero_shot_definitions.py`、12 個の分割モデルの中央値）。

表 4. ゼロショット検索（N = 19,895）の倍率の定義による違い（12 分割の中央値）。原著は効果量による重み付きの値を、「overall」（遺伝子が学習から除かれ、文脈は既知）と OOD（文脈も除かれた場合）として報告している ([1](#ref-1))。

| Query set | Unweighted fold | Effect-weighted fold |
| --- | ---: | ---: |
| All queries pooled | 17.5 | 26.9 |
| Gene withheld, context seen | 17.0 | 26.2 |
| Gene and context withheld (OOD) | 9.0 | 13.5 |

効果量による重み付けの 26.2 倍と 13.5 倍は、原著が報告している値と一致した ([1](#ref-1))。ノックダウンの効果量による重み付けには、効果のない摂動は取り出せないという根拠がある。重み付きと重みなしは、一方が他方を訂正するのではなく、別の問いに答える。重みなしの倍率は、重み付きより小さく、分割ごとの比の中央値は 1.52（範囲 1.47〜1.58）だった。画面ごとに見ると、重みなしの top-10 recall は 0.0009 から 0.315 まで幅がある（表 5）。必須遺伝子を対象とする 4 つの画面（K562 essential、HepG2、RPE1、Jurkat）は問い合わせの 0.44% で、全ヒット（真の摂動が top-10 に入った問い合わせ）の 26.4% を占める。この 4 画面を除くと、画面とモデルの水準で重みなしの倍率は 8.4 倍から 6.2 倍になる。

表 5. 画面ごとの重みなし top-10 recall と、同じ値を与える単一の d′（N = 19,895、一部の画面のみ。全 22 画面は `outputs/tables/effective_dprime_screens.csv`）。有効な d′ は、効果量の構成が異なる画面の間では比べられない。

| Screen | Queries | Top-10 recall | Fold | Effective d′ |
| --- | ---: | ---: | ---: | ---: |
| K562 essential (Replogle 2022) | 876 | 0.3151 | 627 | 2.82 |
| Zhuang 2026 | 4,956 | 0.0420 | 83 | 1.57 |
| X-Atlas HCT116 | 110,520 | 0.0045 | 8.9 | 0.68 |
| Marson 2025 D3 Stim48hr | 41,904 | 0.0009 | 1.9 | 0.18 |

この幅は、公開値の中にも問い合わせの識別力の差が大きいことを示す。表 2 の混合の当てはめと同じ向きの観察だが、直接の確認ではない。画面ごとの値は、1 つの画面の中でも混合である。プールした倍率は、どの画面が何件の問い合わせを持つかで決まる。

もう一つの確認点は棄権である。データセットごとの RNA fingerprinting のアンサンブルは、答えを出さない選択肢を持ち ([4](#ref-4))、原著の図 S4 の元データ ([5](#ref-5)) によると、22 データセットの 1,579,672 細胞の ID で 20.3%、210,280 細胞の OOD で 53.9% の細胞を棄権する。原著の図 S4C の元データでは、OOD の top-10 recall は、全細胞では 0.086、棄権しなかった細胞に限ると 0.136 であり、同じ細胞での ExPert は 0.226 から 0.255 になる。これらのパネルは上の棄権の割合と集計が異なり、単純な積としては整合しない。両者の差は調整していない。原著は、答えた細胞でも ExPert の優位が保たれると報告している ([1](#ref-1))。棄権のある手法の top-k は、棄権の割合と、答えた細胞での正解率が混ざった値である。比較には、答えた割合（coverage）と答えた中での正解率の両方が必要になる。

## 考察

指標ごとに数字が違う理由の一部は、尺度の違いで説明できる。この尺度は換算のための見方であり、ExPert の得点分布についての証拠ではない。正規化した識別スコア、順位の割合、top-k、MRR は、一つの d′ の単調な関数であり、N を決めれば互いに換算できる（表 1）。換算できないのは、次の 3 つである。

- N が異なる倍率（図 4）
- 問い合わせの構成が異なるプール値（表 4 と表 5。誤りではなく別の問いである）
- 棄権のある手法の top-k

公開された ExPert の曲線は、問い合わせの識別力が一様でないとすると、0.01 程度で内挿でき、MRR も再現できた。曲線の形は、強い問い合わせと弱い問い合わせの混合、または連続的な分布のどちらでも説明でき、公開値だけでは区別がつかない。原著の主張、すなわち学習から除いた文脈で既存法の 2 倍以上の recall を得たこと ([1](#ref-1)) は、このモデルによって弱まらない。ここで調べたのは、報告された数字の読み方である。

評価の設計では、ガウスモデルでは必要な d′ が N に対して緩やかにしか増えない（表 3）ため、N の異なる課題を比べるときは、倍率ではなく N を併記した top-k 曲線の方が安定した比較になる。recall は候補リストの定義（遺伝子単位か摂動単位かの重複など）にも依存する。候補を 100 個に絞れば、top-10 recall 50% に必要な d′ は 1.30 に下がる。Virtual Cell Challenge の識別スコアを d′ へ換算するには、採点の距離と候補集合が違うため、実データの値が要る ([2](#ref-2))。順位指標を持つ PerturBench ([3](#ref-3)) も同様に、順位の割合として換算できる範囲にとどまる。本稿では、それらの個別の値を換算していない。

## 限界

- **モデルの仮定：** 等分散のガウス分布を仮定した単純なモデルである。実際の得点分布の裾や候補間の相関は扱っていない。候補が互いに似ている（遺伝子ファミリーなど）と、独立な他の候補という仮定が崩れる。モデルでは同点を考えていない。
- **当てはめ：** 公開された要約曲線（分割と摂動の平均）への当てはめであり、問い合わせごとの生データではない。平均化そのものが混合を作りうる。3 パラメータの当てはめは、3 つの当てはめ点で一意に決まる。パラメータ、RMSE、有効な d′、表 4 の中央値の不確かさは計算していない（分割ごとの比の範囲だけを示した）。
- **AUROC の定義：** 公開値の AUROC の定義は、読んだ範囲の原著本文には書かれていなかった。モデルの AUROC との一致は、定義が同じ場合の整合性にとどまる。
- **外挿：** N = 19,895 への外挿は、単一 d′ と混合で 2 倍以上違う（0.148 対 0.312）。予測として使わない。
- **未読の資料：** RNA fingerprinting の論文 ([4](#ref-4)) は本文の前半を、PerturBench ([3](#ref-3)) は前半を読んだ。後半は読んでいない。Systema など順方向の評価の文献は、本文を読んでいないので引用していない。
- **データ：** ExPert の公開データは図の要約値であり、生データからの再計算ではない。ExPert はプレプリントで、査読を受けていない。著者の利害関係は論文の記載のとおり（著者の一人が NVIDIA 所属で、別の著者が複数の企業のコンサルタント）。
- **探索的な解析：** 混合の当てはめ、保留した k の検証、画面ごとの有効な d′ は結果を見て加えた。
- **AI の利用と査読：** 本稿は AI（Claude）を使って書き、同じ著者が依頼した AI による査読を 3 回受けた。人間の第三者による確認ではない。

## 結論

候補の中から真の摂動を当てる指標は、問い合わせの識別力 d′ と候補数 N を決めれば、top-k、MRR、順位の割合に基づく識別スコアの間で換算できる。ExPert の公開された recall@k には、全問い合わせで同じ d′ を置くモデルは合わず、問い合わせごとに d′ が異なるモデルが保留した k と MRR を再現した。ただし、2 成分か連続分布かは公開値からは決まらない。倍率は N、重み付け、問い合わせの構成に依存し、棄権のある手法の top-k は答えた割合と正解率が混ざる。これらを併記しない限り、論文の間で倍率や top-k を直接には比べられない。この結論は、等分散ガウスの仮定、公開された要約値、未確認の AUROC の定義に依存する。
