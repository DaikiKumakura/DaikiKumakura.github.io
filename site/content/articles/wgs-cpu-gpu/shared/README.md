# wgs-cpu-gpu

Reproduce the numerical illustration with Python 3.12 or later:

    python reproduce.py

Only the Python standard library is required. The command writes illustration.json beside the script.
Inputs are explicit in reproduce.py. These are explanatory calculations, not empirical reanalyses of the cited research.
The runtime inputs are the poster's reported values, not independently measured times.
No random sampling is used. The supplied illustration.json records the executed calculation.
See the article for definitions, assumptions, sources and limits.
