採血を増やせば曝露反応の傾きはどこまで戻るのか。測定のたびに変わる誤差なら平均で小さくなる。同じ患者の測定に共通する誤差は平均にも残る。血圧と血管リスクの研究では反復測定を用いた回帰希釈の補正が行われている ([1](#ref-1))。ここでは、反復測定が何を識別するかを仮想の曝露反応で確かめる。

## 反復で小さくなる誤差と残る誤差

真の曝露を $X$、反応を $Y=α+βX+ε$ とする。同じ患者の第 $j$ 回の測定を $W_j=X+b+u_j$ と置く。$b$ は患者内で共通、$u_j$ は測定ごとに独立で、$X$、$b$、各 $u_j$、$ε$ は互いに独立とする。$X$ と $u_j$ の分散はそれぞれ1。$m$ 回の平均値で $Y$ を単回帰すると、共分散は $β$、平均曝露の分散は $1+Var(b)+1/m$ だから、真の傾きがゼロでなければ、その比はその分散の逆数になる。

**表1. 真の傾きに対する推定対象の比**

| Measurements | No shared error | Shared error variance 0.25 |
| --- | ---: | ---: |
| 1 | 0.500 | 0.444 |
| 4 | 0.800 | 0.667 |
| 16 | 0.941 | 0.762 |
| Infinite | 1.000 | 0.800 |

表1の右列では、2回の測定間の相関は $1.25/2.25=0.556$。単回測定の傾きをこの相関で割っても真値の80%になる。測定間に共有される分散1.25のうち、真の曝露の分散は1だけだからだ。同じ測定法の反復が捉えるのは、曝露と共通誤差を足した分散である。同じ曝露を、真の曝露や元の測定誤差と無相関な誤差をもつ別の方法でも測れば、方法間の共分散から曝露の分散を切り分けられる。

ここで求めたのは母集団の線形回帰係数である。濃度が経時的に変動する場合、誤差が転帰と関連する場合、薬効が非線形に立ち上がる場合には、この比をそのまま使えない。
