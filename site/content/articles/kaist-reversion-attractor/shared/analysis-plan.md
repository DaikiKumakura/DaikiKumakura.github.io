# 解析計画（固定版）：「大腸がん細胞が正常様の腸細胞に戻った」は、公開RNA-seqで何と言えるか

固定：2026-10-12。以下の計算（差次発現、遺伝子セットの得点）を一度も実行していない段階で書く。変更する場合は理由と日付を末尾に追記し、元の設定の結果も残す。

**事前に見たもの（開示）：** 計画の前に、公開カウント表の次の点だけを見た。ライブラリサイズ、MYB・HDAC2・FOXA2・MYC・KRT20・VIL1・CDX2・TP53・GAPDH の生カウント。この結果から、HCT116 で FOXA2 がほぼ検出されないことと、細胞株によりノックダウンの強さが違うことを知っている。それ以外（遺伝子セットの得点、差次発現）は未計算。

## 対象

Gong ら（Adv Sci 2025、doi:10.1002/advs.202402132）。単一細胞のブール網羅モデル（BENEIN）で MYB・HDAC2・FOXA2 を「マスター制御因子」とし、3つを同時にshRNAでノックダウンした大腸がん3細胞株（HCT116、CACO2、HT29）が、「正常様の腸細胞へ戻る」と報告された。公開データは GEO GSE327208（各細胞株で、対照 N と3つ同時ノックダウン MHF、各2反復）。

## QOI

公開されたRNA-seq（細胞株ごとに2反復ずつ）は、(1) 3つの標的がそれぞれの細胞株で発現し、実際に減っていたか、(2) 「腸の上皮（腸細胞）の遺伝子プログラムが、ほかの系統より特異的に上がった」と言えるか、(3) 増殖関連のプログラムが下がったか、(4) 細胞株をまたいで同じ方向の変化か、をどこまで示すか。

## COU

論文の主張「正常様の腸細胞への復帰」を、公開データで読み直す研究上の評価である。治療効果、薬としての標的の妥当性、論文の他の実験（マウス、ウェスタン）の評価には使わない。モデルが判断に与える影響は低い。誤判断の帰結：復帰を示すと読みすぎれば、増殖の停止による二次的な変化を「分化」と取り違える。逆に、読みすぎを恐れて、実際に存在する腸系統のシグナルを見落とす。

## データ（固定）

`data/raw/` のカウント表3つ（GSE327208）。遺伝子セットは `data/genesets/`：MSigDB Hallmark v2023.2（MYC_TARGETS_V1・V2、E2F_TARGETS、G2M_CHECKPOINT、WNT_BETA_CATENIN_SIGNALING）、Enrichr 版の Tabula Sapiens（468の細胞種セット）、Enrichr 版の PanglaoDB（Enterocytes）。

## E1：標的の発現とノックダウン

- 規格化：遺伝子ごとにカウント/ライブラリ合計（CPM）。
- 「発現」：対照2反復の平均 CPM ≥ 2。
- ノックダウン率：1 − (MHF 平均 CPM / N 平均 CPM)。
- 判定：発現しない標的は、その細胞株では操作になっていない。報告：細胞株×標的の表。

## E2：遺伝子セットの得点

1. 解析する遺伝子：どちらかの条件の平均 CPM ≥ 1。
2. 遺伝子ごとの log2FC = log2((MHF平均 CPM + 0.5)/(N平均 CPM + 0.5))。
3. セット得点 = 解析対象の遺伝子のうちセットに含まれるものの log2FC の平均（含まれる遺伝子が10未満のセットは除く）。
4. 帰無分布：解析対象の遺伝子から、同数の遺伝子を、対照の平均 CPM の十分位ごとに層別して無作為抽出（10,000回、seed 20261012）。z = (得点 − 帰無平均)/帰無SD、経験的両側p。遺伝子間の共発現を無視するので、zは強く出る（反保守的）。そのため E3 の順位を併用する。
5. 主セット：Tabula Sapiens の「Large Intestine-mature Enterocyte」と「Large Intestine-immature Enterocyte」、PanglaoDB の「Enterocytes」。対照セット：Hallmark の増殖・WNT 5セット。

## E3：特異性（順位）

Tabula Sapiens の全セット（解析対象の遺伝子が15以上）について、各細胞株のzを計算し、主セットの順位（上位から何%か）を出す。腸の他の細胞種（goblet、幹細胞、transit amplifying、paneth、enteroendocrine）の順位も並べる。

## 判定規則（事前）

- **R1（腸細胞プログラムの上昇）：** Large Intestine-mature Enterocyte の z > 2 かつ経験的 p < 0.05 が、3細胞株すべてで成り立つ。
- **R2（特異性）：** Large Intestine-mature Enterocyte の順位が、Tabula Sapiens 全セットの上位10%に入る細胞株が、3つのうち2つ以上。
- **R3（増殖の低下）：** MYC_TARGETS_V1、E2F_TARGETS、G2M_CHECKPOINT のzが、いずれも −2 未満になる細胞株。細胞株ごとに報告する。
- **R4（反復の安定）：** 2つの対（N1 と MHF1、N2 と MHF2）それぞれで同じ得点を計算し、符号が一致するか。
- **R5（細胞株間の一致）：** 遺伝子ごとの log2FC の Spearman 相関（細胞株のペア、解析対象の遺伝子全体）を報告する。
- 「復帰」と言えるのは R1 と R2 が両方成り立つ場合だけ。一部だけなら「部分的」、どちらも成り立たなければ「このデータでは言えない」と書く。

## 言わないこと

正常な細胞への復帰の有無（このデータセットに正常組織の参照がなく、論文のTCGAとの比較を再現しない）、機能的な分化、マウスの結果、薬としての可能性、モデル（BENEIN）の予測精度。

## 既知の限界

各条件2反復、細胞株3つ。個別遺伝子の検定はしない（反復が少なすぎる）。バルクRNA-seqでは、分化と増殖停止を分けられない。Enrichr の遺伝子セットは、元の単一細胞データから作られた近似である。
