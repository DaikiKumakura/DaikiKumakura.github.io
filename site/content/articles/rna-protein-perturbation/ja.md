Virtual Cellや摂動予測モデルの多くは、RNAの発現で学習し、摂動の後にRNAがどう変わるかを予測する。しかし、薬の標的や、免疫細胞が認識する表面の分子の多くはタンパク質である。RNAの変化は、タンパク質の変化をどこまで代弁するのか。

2026年10月、プロテオミクスの研究者であるNikolai SlavovはXで、Philip Ballの著書［3］を紹介した。著書の主張は、遺伝子を生命の設計図とみなす見方が単純すぎる、というものである。Slavovは関連して、ゲノムの先で起こること（RNAからタンパク質への翻訳など）の重要性を強調した。本記事は、この論点に関わる問いを、公開データで確かめたものである。両氏が本解析の結果を支持しているという意味ではない。

データは、Frangiehらが公開したメラノーマ細胞のPerturb-CITE-seq（2021年）である［1］。Perturb-CITE-seqは、CRISPRで遺伝子を1つずつノックアウト（機能を壊すこと）したうえで、1細胞ずつRNAと表面タンパク質を同時に測る方法である。原著自体が、RNAに加えてタンパク質を測ることで、RNAだけでは見えない免疫逃避の仕組みを調べた研究である。

先に結論を述べる。
- **ノックアウトした遺伝子そのもの：** 遺伝子 × 条件の組で、タンパク質がはっきり下がった16組のうち5組では、mRNAの低下が0.1未満だった（この数え方は結果を見た後に決めた。計画どおりの指標では30組中11組）。PD-L1（CD274）は、3条件すべてでタンパク質が大きく下がる一方、mRNAの変化はほぼ0だった。
- **他の遺伝子を壊したときの間接の効果：** 13,251の組で、RNAの変化とタンパク質の変化の相関は0.26だった。測定のノイズによる弱まりを補正しても0.42（感度解析で0.40〜0.52）にとどまった。相関0.42は、タンパク質の変化のばらつきのうち、RNAの変化で直線的に説明できる部分が2割弱（0.42² ≈ 0.18）であることを意味する。
- **典型例：** B2Mを壊すと、HLA-A（の抗体で測った）タンパク質は大きく下がったが、HLA-AのmRNAはほぼ変わらなかった。B2Mは、HLAクラスI分子が細胞の表面に出るのに必要な部品である。
- **読み方：** RNAだけで摂動の効果を予測・評価すると、表面タンパク質の変化の多くを捉えられない。とくに遺伝子を壊す摂動では、標的そのもののRNAは効果の指標にならないことがある。

## 同じ細胞のRNAと表面タンパク質を比べる {#_1}

**問い（QOI：question of interest）：** CRISPRノックアウトで、ある遺伝子のmRNAの変化は、その遺伝子がコードする表面タンパク質の変化をどこまで予測するか。
- (a) 直接の標的：ノックアウトした遺伝子そのもののタンパク質。
- (b) 間接の効果：他の遺伝子をノックアウトしたときの、測定したタンパク質の変化。

**使いみち（COU：context of use）：** RNAだけで学習・評価した摂動予測を、タンパク質レベルの判断（標的の発現、表面抗原、免疫からの逃避）に使うときの物差し。特定のモデルの性能は評価しない。

**先行研究との関係：** 細胞や組織の間で、mRNAとタンパク質の量が一部しか相関しないことは、よく知られている［5, 6］。本記事は、摂動による「変化」どうしが、同じ細胞でどこまで一致するかを、ノイズを補正して見たものである。

## データ {#_2}

Frangiehらは、ヒトのメラノーマ細胞で248遺伝子を1つずつノックアウトし、3つの条件で培養した［1］。
- 対照（何もしない）。
- IFNγ（免疫のシグナル分子）で刺激。
- がん細胞を攻撃するT細胞と一緒に培養（共培養）。

本記事では、scPerturbの公開版［2］（CC BY 4.0、登録不要）を使った。
- 218,331細胞。
- 表面タンパク質20種。抗体に付けたDNAのタグを数えて測る（ADT：antibody-derived tag）［7］。
- ほかに、背景の目安になるアイソタイプ対照（標的を持たない抗体）が4種ある。
- 20種のうち、対応する遺伝子のRNAが測られている19種を使った。

## 方法 {#_3}

**値の作り方：**
- **RNA：** 各細胞のカウントを総数10,000に揃え（CP10k）、log1p（1を足して自然対数を取る変換）をかけた。
- **タンパク質：** ADTのカウントを、細胞ごとにCLR（centered log-ratio）で正規化した。CLRは、log1p(カウント)から、その細胞の19種の平均を引いたものである。

**変化：** ノックアウト × 条件ごとに細胞の平均を取り、同じ条件の対照細胞の平均との差を変化とした。30細胞未満の組は除いた。

**ノイズの扱い：**
- ノックアウトの細胞と対照の細胞を、それぞれ乱数で無作為に2つに分けた（乱数の種＝seedを固定）。2つの半分は細胞を共有しない。
- 半分ずつの変化どうしがどれだけ一致するか（信頼性）を、RNAとタンパク質それぞれで求めた。半分の細胞での信頼性を、Spearman–Brownの式で全細胞での値に換算した。この式は、測定を2倍にしたときの信頼性を、半分のときの値から求める。
- 測定のノイズがあると、RNAとタンパク質の相関は実際より弱く見える。そこで、相関を2つの信頼性の積の平方根で割った（減衰の補正）。これは、ノイズが無ければ得られたはずの相関の推定である。
- 「タンパク質が大きく変わった組」は、半分どうしの差から求めたノイズの標準偏差の、3倍以上変わった組とした。

**解析計画と事後の変更：**
- 解析計画は計算前に固定した。
- 最初の計算では、対照の細胞を分割していなかった。見直しの結果、これでは信頼性が高めに出るため、分割するよう直した。補正した相関は0.422から0.423で、ほぼ変わらなかった。
- 結果を見た後に加えた感度解析は、本文でそう明記する。

## 結果1：遺伝子を壊してもその遺伝子のRNAは下がらないことがある {#1rna}

![ノックアウトした遺伝子自身のmRNAの変化と、タンパク質の変化](shared/rna-protein-perturbation/figures/01-direct-targets.png)

図1は、ノックアウトした10遺伝子それぞれについて、その遺伝子自身のmRNAの変化（横軸）と、タンパク質の変化（縦軸）を、3条件で示したものである（10遺伝子 × 3条件 = 30点）。点線は、mRNAの変化が−0.1の位置を表す。

| ノックアウトした遺伝子 | mRNAの変化（3条件の平均） | タンパク質の変化（3条件の平均） |
| --- | ---: | ---: |
| CD274（PD-L1） | −0.03 | −1.02 |
| CD58 | −0.10 | −0.87 |
| CD47 | −0.26 | −1.09 |
| CD44 | −0.26 | −0.75 |
| CD59 | −0.22 | −0.52 |
| IFNGR1（CD119） | −0.19 | −0.50 |
| HLA-A | −0.33 | −0.09 |
| HLA-E | −0.56 | −0.12 |

（単位：mRNAはlog1pの差、タンパク質はCLRの差。どちらも自然対数で、−1はおよそ6割の減少にあたる。変化がほとんど測れなかったCXCR4とKDRは表から除いた。表は3条件の平均で、以下の数え方は条件ごとに判定した。）

**数え方と結果：**
- **計画どおりの指標：** 30組のうち、mRNAの低下が0.1未満だったのは11組（37%）だった。ただしこの中には、タンパク質も変わらなかった組（CXCR4、KDRなど）が含まれる。そこで結果を見た後に、次の数え方を加えた（事後）。
- **対象：** 10遺伝子 × 3条件 = 30組から、CXCR4とKDRの6組を除いた24組を見た。
- **タンパク質がはっきり下がった組：** 16組あった（CLRで0.5以上の低下。この閾値も事後に決めた）。
- **mRNAがほとんど下がらなかった組：** その16組のうち5組で、mRNAの低下が0.1未満だった。CD274は3条件すべて、CD58は2条件（IFNγで0.07、対照で0.099の低下。後者は境界ぎりぎり）である。

**考えられる理由（本解析では確かめていない）：**
- **ナンセンス変異依存mRNA分解（NMD）が完全でない：** CRISPRのノックアウトは、DNAに小さな欠失や挿入を入れて、タンパク質を作れなくする。壊れたmRNAを分解する仕組み（NMD）が十分に働かなければ、mRNAの量はあまり変わらない。
- **測り方：** この方法はmRNAの3'末端を数えるので、編集された位置の違いは見えない。
- **細胞の混在：** 編集されていない細胞が混ざっている。
- **割り当ての誤り：** ガイドRNA（CRISPRで標的を指定する短いRNA）の割り当てを誤っている。
- **条件による誘導：** IFNγなど条件による誘導の影響。

いずれにしても、RNAだけを見ると、これらのノックアウトは「効いていない」ように見える。

**逆向きの例：** HLA-AとHLA-Eでは、mRNAは下がったのに、タンパク質はほとんど変わらなかった。
- **HLA-E：** タンパク質はアイソタイプ対照と同程度の背景レベルで、そもそも測れていない可能性が高い。
- **HLA-A：** 抗体がHLA-Aだけでなく、ほかのHLAクラスI分子（HLA-B、HLA-C）も認識しているなら、説明がつく。クラスI分子を広く認識する抗体（W6/32など）は、CITE-seq用にも市販されている。ただし、Frangiehらが使ったクローンは確認できていない。

**変化が測れなかった2遺伝子：** CXCR4とKDRは、RNAもタンパク質もほとんど変わらなかった。KDRのタンパク質は背景レベルで、この細胞ではもともと発現が低いとみられる。

## 結果2：間接の効果でもRNAとタンパク質の一致は弱い {#2rna}

![間接の効果：mRNAの変化とタンパク質の変化](shared/rna-protein-perturbation/figures/02-indirect-effects.png)

図2は、ノックアウトした遺伝子と別の遺伝子のタンパク質の組（間接の効果）について、mRNAの変化（横軸）とタンパク質の変化（縦軸）を並べたものである。色は組の密度を表す。赤いひし形は、B2Mを壊したときのHLA-AとHLA-Eのタンパク質を示す。横軸の範囲（−0.4〜0.4）の外にある18組は、図に入れていない。

ここでの相関は、ノックアウト248種 × タンパク質19種 × 3条件の組（30細胞以上のもの、13,251組）をまとめて計算したものである。

| 指標（主解析、13,251組） | 値 |
| --- | ---: |
| RNAとタンパク質の変化の相関 | 0.26 |
| 半分どうしの信頼性（RNA／タンパク質、全細胞に換算） | 0.62／0.64 |
| 減衰を補正した相関 | 0.42 |
| タンパク質が大きく変わった組（ノイズの3倍以上） | 576組 |
| そのうちmRNAの変化の向きが一致した割合（偶然なら50%） | 67% |
| タンパク質が大きく変わった組だけでの相関 | 0.49 |

事前に決めた判断の規則は、補正した相関が「0.5未満なら、RNAの変化はタンパク質の変化をよく代弁しない」「0.5〜0.8なら部分的に代弁する」だった。主解析の0.42は「よく代弁しない」側に入る。0.5を超えたのは、事後に加えた感度の1つ（0.52）だけだった。RNAの変化でタンパク質の変化を回帰したときの傾きは0.39だった。

**まとめ方の影響：**
- タンパク質 × 条件ごとに平均を引いて（中心化して）から計算しても、相関は0.27で変わらなかった。タンパク質ごとの平均的な差が、相関を作っているわけではない。
- タンパク質 × 条件ごとに別々に相関を取ると、中央値は0.15だった。1つのタンパク質で見ると、多くのノックアウトでは変化が小さく、相関はさらに低い。

**条件別：** 補正した相関は、対照で0.49、IFNγで0.34、共培養で0.49だった。対照の条件では、RNAの信頼性が0.25と低かった。変化そのものが小さく、補正の値は不確かである。

**感度：**

| 設定 | 補正した相関 |
| --- | ---: |
| 主解析（CLR、全細胞） | 0.42 |
| ガイドRNAが1つ以下の細胞に限る（対照にはガイド未検出の細胞を含む） | 0.40 |
| タンパク質を総ADTで割る正規化 | 0.44 |
| タンパク質をRNAの総カウントで割る正規化（事後） | 0.48 |
| 背景を超える14種のタンパク質に限る（事後） | 0.52 |

事後の2つの感度を加えたのは、CLRの性質のためである。CLRは19種の平均を基準にするので、1つのタンパク質が大きく下がると、他のタンパク質が見かけ上上がる。実際、B2Mを壊したときには、HLA-Aが下がる一方で、他の多くのタンパク質がCLRで上がっていた（中央値0.04〜0.09、最大0.34）。この見かけの変化を避ける正規化でも、補正した相関は0.48〜0.52だった。結論の幅は0.40〜0.52で、説明できる分散にすると2割前後（0.16〜0.27）である。

**B2Mの例：** B2Mを壊すと、HLA-A（の抗体で測った）タンパク質はCLRで0.85〜1.45下がった。一方、HLA-AのmRNAの変化は−0.05〜−0.01だった。
- **理由：** B2Mは、HLAクラスI分子が正しく組み立てられて細胞の表面に出るのに必要である。RNAは作られていても、タンパク質が表面に出てこない。
- **RNAだけを見る予測：** この効果は見えない。
- **全体の相関への影響：** B2Mの組を除いても、補正前の相関は0.27で、ほぼ変わらなかった。

## Virtual Cellの評価をどう読むか {#virtual-cell}

**RNAだけでの評価は、タンパク質での効果の代わりにならない：** 補正後の相関は0.4〜0.5で、表面タンパク質の変化のうちRNAの変化で直線的に説明できるのは2割前後だった。タンパク質が大きく変わった組でも、3組に1組はRNAが同じ向きに動かなかった。免疫からの逃避や、抗体医薬の標的の発現のように、タンパク質で決まる判断に、少なくともこのデータでは、RNAだけの予測をそのまま使うのは危うい。

**ノックアウトの「効き」をRNAで測らない：** 標的の遺伝子そのもののmRNAが下がらないことは、ノックアウトが効いていないことを意味しない。評価の指標として標的のRNAの変化を「効果の大きさ」に使うと、効果を見落としうる。

**タンパク質の側にも測定の限界がある：** 抗体で測る表面タンパク質は、20種程度に限られる。また、抗体の特異性や背景の影響を受ける。RNAとタンパク質のどちらが「正しい」かではなく、両方を測ったときに、どこで食い違うかを知ることが大切である。

## 判断できること・できないこと {#_4}

**判断できること：**
- このデータ（メラノーマ細胞、CRISPRノックアウト、表面タンパク質19種）では、RNAの変化とタンパク質の変化の相関は、ノイズを補正しても0.4〜0.5程度にとどまる。
- ノックアウトした遺伝子のタンパク質がはっきり下がった組のうち、約3分の1で、mRNAはほとんど下がらなかった（事後の数え方）。

**判断できないこと・限界：**
- **一般化：** 細胞内のタンパク質や、リン酸化などの修飾、他の細胞種、ノックアウト以外の摂動（阻害剤、CRISPRa）に当てはまるかは分からない。
- **対象の偏り：** 19種のタンパク質は、免疫に関わる表面分子に偏っている。
- **抗体の特異性：** 抗体が別の分子も認識している可能性がある（HLA-Aなど）。
- **正規化：** タンパク質の正規化の方法で値が変わる（感度で幅を示した）。
- **時間差：** RNAとタンパク質は同じ時点で測っており、時間差（RNAが先に変わり、タンパク質が後で変わる）は分からない。
- **不確かさ：** 向きの一致率や相関の信頼区間は計算していない。

## 実装の確かめ {#_5}

- **独立の再計算：** h5pyでファイルを直接読み、総カウントの計算、CLR、群の平均を別のコードで書き直した。直接の標的の値は差5×10⁻⁶以下で一致した。間接の効果の相関（0.26475）と組の数（13,251）も一致した。
- **単体の検査：** 合成データで、次の4点を確かめた。
  - 同じ条件の対照との差の計算。
  - Spearman–Brownの式。
  - 減衰の補正で真の相関を回復できること。
  - CLRの各行の和が0になること。
- **再現性：** 同じseedで再実行すると、結果のファイルがバイト単位で一致した。入力はSHA-256で固定した。
