## 背景と目的 {#article-introduction}

文献確認日：2026年10月18日。公開された小児ALL維持療法の投与履歴・実測ANCを再解析した。薬物濃度を測定したデータではないため、PKパラメータの新規推定ではなく、固定した薬物入力モデルと母集団PDモデルによる予測を扱う。

小児急性リンパ性白血病（ALL）の維持療法では、6-メルカプトプリン（6-MP）とメトトレキサート（MTX）を使用し、血球数を見ながら投与量を調整する。薬物による骨髄抑制には遅れがある。今日の投与量と今日の好中球数だけを見ても、数週間後の推移が分かるとは限らない ([1](#ref-1), [2](#ref-2))。

では、初期の投与記録と好中球数でモデルを個人更新すれば、将来の好中球数をよりよく予測できるだろうか。

**このモデルでは基準ANCの個人更新による追加価値を確認できず、投与ルールの最適化には進まなかった。** 評価患者31例のMAEは、最終記録量を続ける条件で個人更新0.727 G/L、直近ANC0.791 G/L、母集団値のみ0.711 G/Lだった。個人更新と直近ANCとの差の95%区間は0を跨いだ。

## 28日先のANCを予測する条件 {#_1}

**表1．** 問いと解析の使用範囲。

| 項目 | 定義 |
| --- | --- |
| QOI | 維持療法開始から84日までの記録を用いた個人更新は、その後28日間のANC予測を、直近ANCをそのまま使う予測や母集団パラメータだけの予測より改善するか。 |
| COU | モデル補助投与の研究に進む前に、個人更新の予測性能と不確実性を評価する。患者の用量調整や臨床判断には使用しない。 |
| 主な評価量 | 評価患者ごとのMAEを同じ重みで平均した値。差の95%区間は患者単位の再標本化で計算する。 |

投与ルールを最適化する前に、その土台になる予測が単純な方法を上回るか確かめる。予測が悪ければ、精巧な投与シミュレーションを追加しても根拠は強くならない。

## 取得したのは濃度ではなく投与とANCの記録 {#anc}

Jostらの原著には、116例の6-MP投与履歴、実測ANC、体格情報を含む補足CSVがある ([1](#ref-1))。`Data_Sheet_2.CSV`には実測値の`DV`と、原著モデルによる予測値の`IPRED`が同居している。

**本解析ではIPREDを使わない。** 別の補足CSVにある原著の個人別推定値も、事前分布・初期値・評価の正解として使用しない。

**表2．** 入力データの監査。

| 監査項目 | 件数・対応 |
| --- | --- |
| 患者 | 116例 |
| 全イベント | 55,305件 |
| 正の投与量を持つ投与イベント | 49,408件 |
| 実測ANC | 5,897件 |
| 欠損セル／完全重複行 | 0／0 |
| ANCが0と記録された観測 | 2件。いずれも評価群の112日より後にあり、今回の学習・校正・主要採点には入らない。対数モデル用の整形では検出限界を推測して置換せず除外 |

投与イベントがない日は、記録上の入力を0とする。ただし、それが実際の休薬、記録の欠落、服薬状況のどれを意味するかまでは確認できない。処方された量と実際に服用された量も同一とは限らない。

元の治療はMTX併用であり、原著でも独立した薬効の識別に限界があった ([1](#ref-1))。以下の感受性を6-MPだけの純粋な薬理学的感受性とは解釈しない。TPMT・NUDT15などの遺伝子型も、今回のCSVから推定しない。

原著は5,897件のANCから、CRP >5 mg/Lの前後2週間に相当する1,150件を除き、4,747件でモデルを推定している ([1](#ref-1))。今回のCSVにはCRP列も除外フラグもなく、この除外を再現できない。本解析は公開CSV全体を出発点とするため、原著と同じ解析対象の再推定ではない。感染に関連した変動を含む可能性があり、予測誤差を個人更新の性能だけに帰属させない。

## 未来を見ない分割を先に決める {#_2}

乱数シードを固定し、患者を学習60例、予測区間の校正20例、評価36例へ分けた。学習には168日までの記録を使用するが、評価患者の個人更新には84日までしか使わない。患者間の分割と、患者内の時間分割を併用した。

学習患者のうち、168日までの正のANCが4件未満だった1例を除き、実際の母集団推定は59例で行った。個人更新には84日までに正のANCが4件以上、評価には84日超112日以下に正のANCが1件以上あることを条件とした。この条件を満たしたのは、校正17例、評価31例だった。

これは新しい施設・別試験による外部検証ではない。構造と固定PK部分は同じ116例を使った公表研究に由来するので、完全に独立したモデル開発・検証と呼ぶこともできない。ここで改めて分離したのは、**本解析のパラメータ推定・個人更新・採点**である。

## 固定する部分と推定する部分 {#_3}

薬物入力には原著の3区画構造を使用する ([1](#ref-1))。投与量をmg、時間をdayとし、投与時に吸収区画へ0.22×投与量を加える。

\[
\dot X_g=-31.2X_g,\qquad
\dot X_c=31.2X_g-12.72X_c
\]

\[
\dot E=0.019\times9.9216X_c-k_E(BSA)E
\]

ここでEは実測濃度ではなく、原著の6-TGN区画に対応する固定モデル出力である。絶対的な細胞内濃度として検証していない。([Original paper Table 2](https://doi.org/10.3389/fphys.2020.00217))のday単位の数値に合わせ、\(k_E=0.219(BSA/1\,\mathrm{m^2})^{1.16}\)を使用した。原著式2の係数は0.00914で、表と約24倍異なる。これを黙って同じ値として扱わず、**Table 2を採用した条件付きの再実装**とする。CL・V・Fを血中濃度から推定した解析ではない。BSAは各患者の最初の記録値に固定した。

骨髄の増殖区画P、3つの成熟区画T、循環ANCのNを以下で表す。

\[
\dot P=k_{tr}P\left[(1-sE)\left(\frac{B}{N}\right)^\gamma-1\right]
\]

\[
\dot T_1=k_{tr}(P-T_1),\quad
\dot T_2=k_{tr}(T_1-T_2),\quad
\dot T_3=k_{tr}(T_2-T_3)
\]

\[
\dot N=k_{tr}T_3-2.3765N
\]

初期状態は薬物入力0、\(N(0)=B\)、\(P(0)=T_1(0)=T_2(0)=T_3(0)=2.3765B/k_{tr}\)とする。維持療法開始前の骨髄の状態を実測したものではなく、モデル上の平衡を仮定している。

推定するのはB、感受性s、成熟速度\(k_{tr}\)、フィードバック指数\(\gamma\)の母集団値である。最初はBとsの両方に個体間変動を置いたが、学習データで感受性の対数標準偏差が設定上限1.5に達した。校正・評価データを見る前に感受性の個体間変動を外し、Bだけを個人更新する簡潔なモデルへ変更した。感受性を個人ごとに推定できた、という結果ではない。

\[
\log B_i=\log B_{pop}+\eta_{B,i},\qquad
\eta_{B,i}\sim N(0,\omega_B^2),\quad s_i=s_{pop}
\]

観測には対数正規誤差を使う。残差の時系列相関は明示的にはモデル化しない。患者単位の再標本化は評価指標の不確実性を扱うもので、この残差仮定を正しくする操作ではない。

母集団推定では17点のGauss–Hermite求積による周辺尤度を最大化し、25点でも確認する。個人更新は母集団分布を事前分布とした基準ANCのMAP推定であり、84日以後のANCを使わない。2つの初期値から推定し、数値積分の刻み幅と未来情報の遮断も検査する。

**表3．** 母集団パラメータの推定値。

| 推定値 | 値 | 単位・定義 |
| --- | ---: | --- |
| baseline | 1.661 | G/L、モデル上の基準ANC |
| slope | 0.06157 | 固定モデル出力Eの逆尺度。実測6-TGNへの感受性ではない |
| ktr | 0.1398 | day⁻¹ |
| gamma | 1.2 | 無次元 |
| omega_baseline | 0.2792 | log Bの標準偏差、無次元 |
| sigma_log | 0.4946 | 対数残差の標準偏差、無次元 |

母集団係数の信頼区間は計算していない。ランダム効果の標準偏差と、パラメータ推定の標準誤差は異なる。

最良の開始点でも\(\gamma\)は設定上限1.2に達し、別の開始点では異なる感受性・フィードバックの組合せになった。数値最適化が終了したことと、各係数が十分に識別されたことは同じではない。以下の予測を、特定の生理学的パラメータを精度よく決定した証拠とは解釈しない。

## 将来の投与量を知っているかで問いが変わる {#_4}

評価は二つの入力条件に分けた。

**表4．** 将来投与の入力条件。

| 入力条件 | 84日以降に与える投与情報 | 解釈 |
| --- | --- | --- |
| 最終記録量を継続 | 84日までの最後の正の投与量を、以後毎日投与すると仮定 | 変更なしというシナリオ。実際の将来処方を知っているわけではない |
| 将来の投与記録を使用 | 実際に記録された84日超112日までの投与量 | 投与履歴が既知の場合の後ろ向き条件付き予測。前向き予測とは呼ばない |

血球数が変わったために投与量が変更された可能性がある。後者には、血球数の変化を受けた治療行動の情報が含まれ得る。したがって、後者で誤差が小さくても、その性能をそのまま実際の投与判断時に期待できない。

比較する予測は、直近ANCを維持する単純予測、母集団値だけの予測、個人更新した予測の3つとした。

評価31例のうち、24例は将来の投与記録が最終量継続のシナリオと異なり、7例は記録上同じだった。変更群では、異なる投与を受けた後のANCへシナリオ予測を照合している。したがって、このMAEは「本当に最終量を継続した場合のANC」という反実仮想の検証ではなく、実際の処方変更を含めて予測する仕組み全体の前向き性能でもない。

個人更新は直近ANCより小さいMAEの点推定になったが、差の区間は0を跨いだ。また、今回の個人更新は母集団値だけの予測より良くなかった。個人更新の追加価値を確認できたとは言えず、同等であると証明したわけでもない。評価患者31例という規模と、このモデル・84日時点・28日間という条件に限った結果である。

患者によって採血回数が違うため、観測が多い患者が結果を支配しないように、まず各患者の誤差を平均した。95%区間は評価患者を単位に2,000回再標本化して求めた。多数の観測を独立な患者として数えていない。

**図2．** 別の校正患者で作った90%誤差帯の、評価患者における被覆率。

予測帯は、別の校正患者における絶対対数誤差の90パーセンタイルから作った。全パラメータの事後分布を伝播した完全なベイズ予測区間ではなく、小規模な校正標本で得た経験的な誤差帯である。記録単位で校正し、被覆率の要約は患者を等重みとしたので、90%の被覆を保証するものでもない。

積分刻みを0.25日から0.125日にしたとき、評価時点の個人予測の最大絶対差は0.000246 G/Lだった。未来の投与入力を変えても84日以前のMAP推定が変わらないことを確認し、96件のMAP最適化は終了条件を満たした。Gauss–Hermite求積を17点から25点に増やした同じ係数での負の対数尤度差は0.484だった。これらは数値・情報境界の検査であり、臨床的な妥当性の検査とは区別する。

原著の係数表記差への探索的なストレス計算として、代謝物消失係数と感受性を両方24分の1にした条件でも比較した。他の係数と個人更新値は固定したため、再推定した別モデルとの優劣比較ではない。そのMAEは最終記録量継続で0.739、将来投与記録を使う条件で0.739 G/Lだった。定常的な作用の尺度を揃えても応答の遅れは変わり得る。この計算で原著のどちらの表記が正しいかを判定することはできない。

## 投与ルールの比較へ進めるか {#_5}

事前に、両入力条件で個人更新が直近ANCより良く、患者単位MAE差の95%区間上限が0未満であること、経験的90%誤差帯の被覆率が80%以上であることを、投与ルール比較への条件にした。これは研究上の作業ゲートであり、臨床導入の基準ではない。

**この条件は満たさなかったため、仮想患者で投与ルールを最適化する解析は行わない。** 患者別の将来予測を確認する前に、モデル自身が作った仮想患者で投与成績を比較すると、仮定に有利な結果を作ってしまう可能性がある。今回の完成点は、実測ANCで予測の限界を確認したところにある。

ANCは骨髄抑制の指標であり、再発や生存を直接予測しているわけではない。仮にANCを狙いどおりに動かせても、それだけで抗白血病効果を維持したと言うことはできない。

## 考察 {#_6}

公開補足資料の実測値を選び直し、患者単位の分割、過去だけによる個人更新、将来投与情報の有無を区別して予測を評価した。数式への適合と、投与判断に必要な将来予測は別の問題である。

本解析の対象は同じ公表データ内であり、施設差、服薬状況、感染、併用薬、遺伝子型、初期の骨髄状態などを十分には表していない。固定PK係数の表記差も未解決である。これらの影響とモデル構造による不一致は、今回の比較では分離できていない。

結論は、個人別感受性を推定できなかった今回のモデルでは、基準ANCのMAP更新の追加価値を確認できなかった、という範囲に限る。感受性や現在の骨髄状態の逐次更新を含むMIPD一般や、6-MPの投与最適化そのものの可能性を否定する結果ではない。

Karppinenらの白血球・CRPの研究は別のコホートであり、本解析のANCデータに併合していない ([3](#ref-3))。
