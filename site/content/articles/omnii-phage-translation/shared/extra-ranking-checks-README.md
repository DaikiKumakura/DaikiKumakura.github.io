# Additional ranking arithmetic

Install scipy and run:

```sh
python extra-ranking-checks.py
```

Inputs are the published aggregate counts24/100,97/100,96/100 and rounded library fraction4.5%. No sequence, strain or clinical data are needed. The script prints binomial-model intervals, ratios to a fixed baseline and rounding sensitivity. The top100 is a selected finite set: its observed fraction is descriptive; these hypothetical binomial intervals are not validated confidence intervals for future design campaigns or clinical outcomes. Original ZIP remains unchanged.
